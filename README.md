# אברהם בקר — עמוד Link in Bio

אתר סטטי (HTML / CSS / JavaScript בלבד). אין צורך בשרת, ב-build או בהתקנות.

## מבנה

```
index.html        מבנה העמוד
style.css         עיצוב
script.js         רשימת המדריכים והקישורים (כאן עורכים תוכן)
assets/
  logo.svg        לוגו AB בזהב (משמש גם כ-favicon)
  background.webp תמונת הרקע
  guides/         קובצי ה-PDF של המדריכים
```

## עדכון תוכן

כל התוכן נערך בראש הקובץ `script.js`:

- **`GUIDES`**: רשימת המדריכים. לכל מדריך יש `title`, `description`, `icon`, `url`, `featured`.
  - כדי להוסיף מדריך, מעתיקים בלוק `{ ... },` קיים ומשנים אותו. הכרטיס נוצר אוטומטית.
  - `featured: true` מציג את הכרטיס בהדגשה זהובה.
  - אייקונים זמינים: `home`, `family`, `will`, `coins`, `layers`, `scale`, `key`, `building`, `document`, `bell`.
- **`SOCIALS`**: קישורי התחתית (אתר, WhatsApp, YouTube, Instagram, TikTok).
  - WhatsApp: `https://wa.me/972501234567` (מספר בפורמט בינלאומי, בלי 0 בהתחלה ובלי מקפים).

כרגע כל הקישורים הם `"#"`, וצריך להחליף אותם בכתובות האמיתיות.

### מדריך להורדה (PDF)

1. שמים את קובץ ה-PDF בתיקייה `assets/guides/`, עם שם באנגלית ובלי רווחים. לדוגמה: `rental.pdf`.
2. ב-`script.js` כותבים: `url: "assets/guides/rental.pdf"`.

כרטיס שמפנה לקובץ מקבל אוטומטית אייקון הורדה במקום חץ, ולחיצה עליו מורידה את הקובץ.
באייפון, וגם בדפדפן הפנימי של טיקטוק, הקובץ בדרך כלל נפתח לתצוגה ושומרים אותו דרך כפתור השיתוף.
מומלץ לשמור את הקבצים קטנים (עד כמה MB) כדי שייפתחו מהר. אפשר להעלות דרך אתר GitHub קבצים של עד 25MB.
קישור שמתחיל ב-`https://` נפתח בלשונית חדשה.

## העלאה ל-GitHub Pages

1. נכנסים ל-[github.com](https://github.com) ויוצרים מאגר חדש (**New repository**), ציבורי (Public).
   לדוגמה: `links`.
2. בעמוד המאגר: **Add file → Upload files**, וגוררים פנימה את כל הקבצים והתיקייה `assets`
   (כך ש-`index.html` יהיה בתיקייה הראשית של המאגר). לוחצים **Commit changes**.
3. **Settings → Pages**. תחת **Build and deployment**:
   Source = **Deploy from a branch**, Branch = **main**, תיקייה = **/ (root)**, ולוחצים **Save**.
4. אחרי דקה או שתיים העמוד יהיה זמין בכתובת:
   `https://<שם-המשתמש>.github.io/<שם-המאגר>/`
5. מדביקים את הכתובת בשדה האתר בפרופיל הטיקטוק.

לעדכון: עורכים את `script.js` ישירות ב-GitHub (אייקון העיפרון) או מעלים גרסה חדשה. השינוי עולה לאוויר תוך דקה-שתיים.
